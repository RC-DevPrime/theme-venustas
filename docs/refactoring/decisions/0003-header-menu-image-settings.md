# ADR-0003：Men／Women 图片映射与双链接设置

- 日期：2026-11-23
- 状态：accepted（本次 Men／Women 范围）
- 模块与影响范围：新 Header 主题区块与样式；无跨页面消费者协议变更
- 批准依据：用户要求基于已确定结构实现 Men／Women 四列、独立配置、Category 移动不折叠、其他列折叠、底部双卡，旧代码保留
- 关联任务日志：[Men／Women](../logs/header/2026-11-23-men-women-navigation.md)
- 替代／被替代 ADR：扩展 ADR-0002，不覆盖原 New 记录

## 背景与证据

New 已用17个动态区块。Shopify 每 section 上限50个，真实主题区块嵌套也计入；若为每张分类图再添加动态块，将超过容量。当前没有六个分类／Style／Collections 原生菜单的后台数据。

## 候选方案

1. 每张分类图单独动态区块、每个 footer 链接单独区块：编辑直观，但本批会超出上限。
2. 图片菜单内八组 URL／图片设置，footer 单块提供主／次链接：保持所需四列结构，总数49，采用。
3. 多 section 拆分面板：可扩充容量，但会改变单一 Header 父子编辑结构，本批不引入。

## 决策

原生菜单有链接时，名称／地址／顺序完全来自菜单，图片按 URL 匹配，标题不参与匹配。未选择菜单时，槽内初始文案用于本地测试；普通菜单同样提供有限初始内容，选菜单后自动替换。未确认的地址留空，不将展示文案当成真实目标地址。

Men／Women 复用样式，各有16个块；Category 不折叠，移动三列图网格。底部一个区块管理桌面左右两个链接，移动 Technology 在双推广卡之前，DOM 与视觉顺序一致。推广默认图由本次 Figma 下载至 assets，上传图片／产品图优先，运行代码不使用临时 URL。

## 后果与验证

当前仅余一个动态区块名额；扩展后续导航前需重新提出容量方案。图映射最多八项，更多菜单项仍显示文字与统一占位图。初始菜单与分类图需商家配置。只做定向静态校验，未验证浏览器、后台资源和线上效果。

## 历史
