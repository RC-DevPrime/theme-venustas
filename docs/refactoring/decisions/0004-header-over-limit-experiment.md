# ADR-0004：保留嵌套分类进行区块超限实验

- 日期：2026-11-24
- 状态：accepted（实验授权，不代表平台兼容性通过）
- 模块与影响范围：新 Header Bundles 面板；不修改其他模块或线上主题
- 批准依据：用户明确要求“不需要控制在50个区块内，直接继续写区块，我测试下超过50个区块能否正常显示”
- 关联任务日志：[Bundles](../logs/header/2026-11-24-bundles-navigation.md)
- 替代／被替代 ADR：仅对本次实验取代 ADR-0003 的容量约束，不否定其历史背景

## 背景与证据

原 New17、Men16、Women16合计49个动态区块。用户尚未批准多 section 迁移，并明确要求测试原结构继续添加真实分类区块。旧 header-group.json 的 Bundle Sale 具有四个分类集合与对应文案。

## 候选方案

1. 活动分类固定字段以保持50以内：助手提出，用户本次明确不采用。
2. 各面板拆为独立 section：上一轮建议，尚未批准实施。
3. 活动面板 → 独立分类块 → 集合商品，保留55个区块用于用户测试：本次采用。

## 决策

新增一个活动面板、四个集合分类、一个固定底部按钮。分类顺序可拖动，集合商品动态读取，沿用现有 Header 资源与生命周期。静态检查发现的语法／引用错误应修复；单纯由用户要求产生的区块超限不自动删减或压缩，也不调高 schema 上限伪装平台兼容。

## 后果与验证

保留完整嵌套编辑结构，但平台能否保存、上传和渲染超过50个区块必须由实际测试确定；未自动上传、发布或使用浏览器。旧代码保留，撤销新增 Bundles 配置即可恢复49块。静态校验与用户的主题测试分开记录。

## 历史

2026-11-24 用户明确纠正50以内的实现方向后采用。本实验不自动延伸到其他面板或发布。
