# ADR-0002：New 导航使用嵌套主题区块

- 日期：2026-11-23
- 状态：accepted（仅本次 New 实施范围）
- 模块与影响范围：Header 新文件与 layout group 引用；保留原有共享消费者契约。
- 批准依据：用户要求先实现 New、八个入口用变量写死、复用旧 New 推广数据；明确选择切换 theme.liquid 至 header-group-new 进行测试。
- 关联任务日志：[New 导航](../logs/header/2026-11-23-new-navigation.md)
- 替代／被替代 ADR：无。历史 Metaobject 文档为未实施提案，本次明确不采用。

## 背景与证据

旧 Header 通过 menu_tag 与 dislay_* 配置分派桌面和移动 snippets。新需求要求 Header → 面板 → 内容区块，内容在主题编辑器维护，不使用元对象。Figma 桌面节点 6226:3641，移动节点 6324:7606。

## 候选方案

1. 复用旧扁平 dislay 配置：改动较少，但不能提供要求的父子编辑结构。
2. 嵌套主题区块：支持真实父子关系与拖动排序，本次采用。
3. Metaobject：用户明确排除，未采用。

## 决策

新增 header-new section、header-group-new 编排及 _header-nav-* 主题区块。仅 New 使用三列与两卡；其余入口暂用 section 变量，后续菜单接入另行授权。复用旧 New 的推广图片、标题和链接，不写入 Figma 临时素材地址。用户明确授权后，layout 切换到新 group；旧代码保留。

## 后果与验证

新交互与旧绑定隔离，保留 Header 高度选择器／事件供页面吸顶逻辑读取。搜索与购物车 sections 保留，但本批无功能入口。首批不实现其他面板、分类图片菜单、商品角标或 Help。验证限于本次新增文件静态检查，不声明浏览器、主题上传或线上效果。

## 历史

2026-11-23 用户收窄范围到 New 并批准测试入口切换后实施。
