# ADR-0001：仓库内 Markdown 重构知识库

- 日期：2026-11-23
- 状态：accepted（用户本次明确要求的知识库方案；业务重构方案仍待审核）
- 范围：技术文档与开发流程
- 批准依据：本次初始化任务明确指定仓库 Markdown、目录和审批边界
- 关联记录：[初始化日志](../logs/2026-11-23-knowledge-base-init.md)

## 背景

重构依次为 Header、Collection、Product Detail，需要跨会话保留源码关系、历史经验和重要取舍。原 docs/SHOPIFY_ARCHITECTURE.md 为空，根 AGENTS 已有开发规则与库存复盘。

## 方案与决策

采用仓库 docs/refactoring 下的项目概要、模块档案、独立日志、ADR 和模板；根 AGENTS 要求按需自动读取、审批后实施及增量更新。保留原有规则，不移动或删除旧文件。

外部数据库／第三方知识平台不在用户允许范围；每次重生成完整文档会扩大维护量并覆盖历史，未采用。没有引入索引服务、应用或工具链。

## 后果

知识与代码可一同评审、版本管理；依赖后续任务遵守 AGENTS，Markdown 自身不会自动监控代码。必须核对当前源码，按变化维护，明确未验证事实，避免文档漂移。撤销本机制可移除本次新增文档和 AGENTS 新增段，不需迁移业务数据。

## 验证与历史

本次仅核对文档结构、路径和改动范围；不做业务代码重构、不提交 Git、不推送。2026-11-23 按用户明确要求建立；无其他技术实施决策被接受。
